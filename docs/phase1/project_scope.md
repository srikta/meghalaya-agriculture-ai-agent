# Phase 1 Project Scope

## Project Title
Rainfall–Crop Intelligence System for Meghalaya

## Objective
The objective of this project is to develop an intelligent agriculture
information system for Meghalaya that integrates rainfall information
with crop area, production, and yield statistics.

The system will organize heterogeneous agriculture-related information
from official sources into a structured and queryable knowledge base.

The project will focus on studying spatial and temporal relationships
between rainfall and agricultural crop performance across districts
of Meghalaya.

## Core Information

The initial knowledge base will contain:

- District and location information
- Rainfall information
- Crop information
- Crop area
- Crop production
- Crop yield
- Year and season
- Source and provenance information

## Initial Analysis Goal

The system will eventually support analysis of relationships such as:

Rainfall ↔ Crop Production

Rainfall ↔ Crop Yield

District ↔ Crop Performance

Year/Season ↔ Rainfall and Production

## Current Scope

Phase 1 will focus on:

- Identifying official data sources
- Identifying source modalities
- Identifying languages
- Understanding source limitations
- Designing the initial knowledge-base schema
- Identifying suitable extraction tools and agents
